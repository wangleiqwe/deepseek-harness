# @deepseek-ai/dsh-client-ui-file-reference

[English](README.md) | 中文

**输入框文件引用插件**：两种向草稿插入会话工作区文件纯文本 `@rel` 引用的方式——`@`-文件菜单（ui-input-trigger 管线中的一个触发源，注册在子智能体分组之上），其目录行带尾部斜杠与文件夹字形；以及回形针文件选择按钮（`conversation.input.left` 工具行槽位中的一个条目），其弹窗把工作区当作目录树浏览：文件夹就地展开/收起，每一层都从宿主的单层列举懒加载，路径编辑器可以把浏览基准目录跳到任意完全限定路径——工作区根目录之下的行以绝对宿主路径引用。两者都取自宿主的有界列举（`host.listFiles` / `host.listLevel`，由 `dsh-host-file-browser` 提供）：触发源按会话缓存一份列举 30 秒（TTL）并对并发请求去重，弹窗每次展开层级时读取、关闭时中止。

行为事实：候选是相对根的路径（正斜杠拼写；目录以 `/` 结尾），按路径或基名做不区分大小写的过滤，顺序保持宿主的广度优先序；没有工作区账户（未分组）的会话或列举失败时，菜单组为空，而弹窗展示自己的说明性表面（无工作区 / 不可读 / 已截断提示）。菜单选中插入带尾部空格的 `@rel ` 以闭合触发词元。弹窗中工作区根目录是初始基准；文件夹行展开/收起，不可读的文件夹回退为收起态并显示行内提示、下次点击重试，路径编辑器按 Enter 把基准跳到输入的目录（工作区根目录按钮可返回）；弹窗确认时把 `@rel1 @rel2` 以单空格分隔追加到草稿末尾（一次机器事务、一步撤销——读写发生在同一同步回合内）。输入处于非 plain 阶段时按钮禁用。所有引用都是纯文本，遵循 [plain-text-reference 决策](../../../.agents/notes/implemented/architecture/2026-07-25-web-input-machine-and-slash-pipeline.md)：无出现身份、无 codec——字面量原样发给模型，由模型用自己的文件工具解析工作区相对路径。

## Model Experience

### 纯文本文件引用

#### What the model sees

每选中一个引用，就把字面量文本 `@<路径>` 追加进用户的提示词——与草稿中显示的文本相同，无任何包裹标记：会话根目录之下为相对路径，在根目录之外的目录中选取时为绝对路径。模型应当把它当作路径（工作目录下的相对路径，或以盘符/`/` 开头的绝对路径），并用文件工具读取；请求的其他部分不变。缓存永远不进入模型。

#### Token effect

只有引用文本本身：每个被选中的文件一个 `@` 词元，按普通提示词词元计费。不注册额外的上下文消息、工具 schema 或提示词段落。

#### KV Cache effect

除上述普通提示词文本外无其他影响；本包既不组装也不发送 provider 请求。

## Known Limitations and Deferred Work

- **草稿无装饰**——`@路径` 词元在输入框中不高亮（文本引用扫描只匹配单词形名称，而路径含分隔符/点号）。路径词表的装饰需要 ui-conversation 扩展扫描。
- **插入总是追加在草稿末尾**——回形针在当前文本之后写入而非光标处；`@` 菜单则替换其触发区间。
- **层级按展开读取**——弹窗只持有已加载的层级；弹窗打开期间代理新建的文件需重新展开文件夹才会出现（重新打开弹窗会重读根目录）。
- **工作区之外的引用是绝对宿主路径**——通过路径编辑器在工作区根目录之下浏览到的行，插入 `@<绝对路径>`；模型必须对照宿主文件系统而非自己的工作目录来解析。
- **跳过策略归宿主所有**——隐藏条目、`node_modules` 与 `.git` 由 `dsh-host-file-browser` 省略；客户端不能按会话修改策略。
